# LocalVoices 6.0

Структура репозитория оформлена по шаблону хакатона: `src/`, `docs/`, `artifacts/demo/`, `artifacts/test-results/`, `config/`.

Локальное Android-приложение для расшифровки разговоров на русском языке. Аудио остаётся на устройстве, а результат можно просмотреть и экспортировать без интернета.

## Что умеет приложение

- импортировать MP3 из памяти телефона;
- записывать разговор через встроенный диктофон;
- преобразовывать речь в текст;
- разделять реплики по говорящим;
- сохранять начало и конец каждой реплики в миллисекундах;
- показывать расшифровку с проигрывателем;
- экспортировать результат в JSON, TXT и SRT;
- сохранять образцы голосов в разделе «Мои голоса».

## Быстрый запуск

1. Установите `LocalVoices-6.0-GigaAM-MP3-Fixed.apk` из GitHub Release на Android 8.0+.
2. Откройте приложение и разрешите доступ к микрофону и файлам.
3. Выберите один из сценариев:
   - **Файл:** «Импорт аудио» → выберите MP3 → «Обработать».
   - **Диктофон:** «Новая запись» → начните и остановите запись → дождитесь обработки.
4. Откройте расшифровку и при необходимости экспортируйте JSON.

Подробности: [INSTALL.md](INSTALL.md). Аннотация для проверяющего: [docs/PROJECT_ANNOTATION.md](docs/PROJECT_ANNOTATION.md). Материалы по шаблону: [docs/](docs/), [artifacts/](artifacts/), [src/](src/).

## Как проходит обработка

`аудио → MediaCodec/PCM 16 кГц → VAD (речь или пауза) → GigaAM ASR → speaker embeddings → кластеризация говорящих → временные метки → локальная LLM для пунктуации → JSON`

В APK встроены GigaAM, Silero VAD, speaker encoder/segmentation и Qwen2.5 через llama.cpp. Облачные API не используются.

## Сборка из исходников

Нужны JDK 21, Android SDK 35, NDK 27.2.12479018 и CMake 3.22.1. Модели хранятся отдельно и уже включены в готовый APK-релиз.

```powershell
./gradlew.bat :core:test :app:assembleGigaam50Debug --max-workers=2 '-Pkotlin.compiler.execution.strategy=in-process'
```

Большой APK публикуется как GitHub Release asset, а не обычный Git-файл: GitHub ограничивает один файл размером 100 МБ.

## Формат экспорта

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

Время указано в миллисекундах относительно начала исходного аудио.
