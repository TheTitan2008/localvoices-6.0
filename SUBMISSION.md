# Комплект сдачи

В GitHub-репозитории должны быть:

1. Исходный код.
2. `README.md`.
3. `INSTALL.md`.
4. `ARCHITECTURE.md`.
5. `LIMITATIONS.md`.
6. `TEST_RESULTS.md`.
7. APK в GitHub Release.
8. Видео демонстрации (ссылка или файл, если размер позволяет).

## Рекомендуемый сценарий видео

Продолжительность: 3–5 минут.

Показать: запуск APK → импорт MP3 → обработка → говорящие и таймкоды → экспорт JSON → короткий пример встроенной записи. В начале назвать версию APK и отметить, что обработка выполняется без интернета.

## Перед отправкой ссылки

- проверить, что ссылка на репозиторий открывается;
- проверить, что APK скачивается из Releases;
- проверить установку на чистом устройстве;
- проверить импорт MP3 и повторный запуск;
- проверить наличие JSON с нужными полями;
- проверить, что в README указан способ запуска обоих сценариев.

Большие APK не хранятся в обычных Git-коммитах: GitHub ограничивает размер одного файла 100 МБ, поэтому APK публикуется как Release asset.
