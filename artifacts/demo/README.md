# Материалы демонстрации

Рекомендуемое видео: 3–5 минут.

Показать по порядку:

1. запуск APK и отсутствие необходимости в интернете;
2. импорт MP3;
3. запуск обработки и готовую расшифровку;
4. говорящих и временные метки;
5. экспорт JSON;
6. короткий пример записи через встроенный диктофон.

Файл видео пользователь добавляет отдельно перед отправкой итоговой ссылки.
