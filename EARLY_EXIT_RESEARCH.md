# Исследование Early Exit

## Что сделано

Проверена идея CTC blank-triggered layer skipping из опубликованной работы. Она требует промежуточной CTC-head, калибровки blank probability и безопасного пропуска последних encoder layers. Это не равно Silero VAD gating и не может быть включено изменением одного параметра текущего GGUF.

## Статус

В текущей версии приложения настоящий Early Exit не включён. Полный inference остаётся доступным. Включение экспериментального пропуска без промежуточной головы могло бы удалить тихую речь и нарушить токенизацию.

## Следующий proof-of-concept

1. Экспортировать GigaAM encoder с промежуточными logits.
2. На русской development-выборке измерить blank precision/recall по слоям.
3. Обучить или дистиллировать промежуточную CTC-head.
4. Сравнить full/early-exit по WER, insertion/deletion и RTF.
5. Включать только при положительном risk–coverage результате.
