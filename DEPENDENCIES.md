# Зависимости и большие файлы

Исходники приложения находятся в этом репозитории. Большие бинарные модели и каталоги сборки исключены из Git, потому что они уже встроены в готовый APK-релиз и превышают практический размер обычного коммита.

Для локальной сборки нужны:

- JDK 21;
- Android SDK 35;
- NDK 27.2.12479018;
- CMake 3.22.1;
- локальный `sherpa-onnx-1.12.15.aar` из `app/libs`;
- pinned native dependencies, которые подготавливает `scripts/bootstrap.ps1`.

Если нужна только проверка решения, устанавливайте APK из GitHub Release: модели уже внутри него, отдельный сервер и скачивание весов не требуются.
