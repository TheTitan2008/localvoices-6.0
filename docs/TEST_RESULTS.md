# Методика и результаты тестирования

## Методика

Проверялись собственные аудио- и видеозаписи во время итераций приложения. После каждой итерации часть исходных файлов удалялась, поэтому ниже приведены сводные наблюдения.

1. Установка APK на Android-эмулятор.
2. Отключение сети.
3. Импорт MP3.
4. Расшифровка, проверка говорящих и таймкодов.
5. Экспорт JSON.
6. Повторный запуск и повторный импорт.

## Результаты

- Определение текста в большинстве проверок было стабильным и пригодным для чтения.
- Наиболее частые ошибки наблюдались в диаризации: короткие реплики, похожие голоса и перебивания.
- Импорт и обработка в медленной конфигурации занимали примерно 1,5 длительности исходного файла.
- Встроенный диктофон удобнее для длинных разговоров, потому что обработка может начинаться по мере записи.
- После исправления Room/DAO импорт MP3 и повторный запуск проходят без падения.

Подробный чек-лист находится в `TEST_RESULTS.md` в корне репозитория.
