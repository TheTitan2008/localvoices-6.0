# Формат результата обработки

## Вход

Приложение принимает MP3 из локальной памяти Android или аудио, записанное встроенным диктофоном.

## Выход

Для проверки задания экспортируется JSON:

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

`start_ms` и `end_ms` — целые миллисекунды от начала аудио. `speaker_id` действует внутри одного диалога.
