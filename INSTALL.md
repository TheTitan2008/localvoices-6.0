# Установка и использование

## Установка

1. Скачайте `LocalVoices-6.0-GigaAM-MP3-Fixed.apk` из раздела Releases.
2. Установите APK на Android 8.0 или новее.
3. При первом запуске разрешите доступ к микрофону и аудиофайлам.
4. Убедитесь, что на устройстве достаточно свободной памяти для встроенных моделей.

Интернет для распознавания не нужен. Модель уже входит в APK.

## Сценарий 1: импорт аудио

`Импорт аудио → выбрать MP3 → открыть карточку записи → Обработать → дождаться статуса «Готово» → открыть расшифровку → Экспорт`

Для проверки лучше использовать MP3 умеренной длины. Очень большие файлы рекомендуется разделить.

## Сценарий 2: запись через диктофон

`Новая запись → начать запись → поговорить → остановить → приложение автоматически сохранит аудио → обработка → расшифровка → Экспорт`

Встроенная запись предпочтительнее для длинных разговоров: приложение может обрабатывать готовые фрагменты по ходу записи.

## «Мои голоса»

`Мои голоса → добавить голос → записать чистый образец речи (от 3 секунд) → сохранить`

Профили помогают сопоставлять повторяющихся участников между диалогами, но требуют проверки пользователем.

## Экспорт

В расшифровке нажмите «Экспорт» и выберите JSON, TXT или SRT. Для проверки задания используйте JSON: корневой ключ — `transcript`, у каждой реплики есть `speaker_id`, `start_ms`, `end_ms`, `text`.
